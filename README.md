Star Catcher, a tiny browser game built from one prompt by an AI agent. A basket slides along the bottom of a night sky, catch the falling golden stars for 10 points each, dodge the grey rocks, 3 lives, 60 seconds on the clock, and the falling speed rises as time runs out. The finished game is shown running in the entry video posted on X from @CryptoidIDN.

## Run it

```sh
node main.ts
```

Then open `out/game.html` in a desktop browser to play. Arrow keys, A/D, or the mouse move the basket, R restarts, and `out/game.html?demo=1` auto-plays a seeded demo game.
